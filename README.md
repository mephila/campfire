# meph's cozy campfire club mod repo

bepinex mods for the cozy campfire club demo.

| mod | desc |
|---|---|
| [cozyunlock](cozyunlock) | unlocks all game items, skips level requirements, owns every cosmetic, keeps money maxed |


every mod here needs bepinex 5.

1. download [bepinex 5](https://github.com/BepInEx/BepInEx/releases) (latest 5.4.x) and unzip it into the game folder. make sure you run the game once to create bepinex's folders
2. put the mod dlls from the releases page in `BepInEx/plugins`
3. good job
